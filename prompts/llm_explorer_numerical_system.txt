Convert the supplied exploration analysis into complete numerical guidance.

This system uses 16 UAVs to collect FOV/COM data and deliver it to GS. The objective is timely useful bits per joule of movement energy. Standard FOV/COM end-to-end deadlines are 15/10 ms.

This request supplies the complete analysis, necessary state, numerical bounds, and historical matrices. Use these inputs to perform the conversion.

[TD3 output]

td3_bias has shape 16x3:
- Rows follow UAV IDs 0-15.
- Columns are speed, heading, vertical.

Normalized actions are decoded as:

v_xy = 5*(speed+1) m/s.
theta = pi*heading rad.
v_x = v_xy*cos(theta).
v_y = v_xy*sin(theta).
v_z = 2*vertical m/s.

Speed and vertical have domains [-1,1]. Heading is periodic in [-1,1). Speed=0 means 5 m/s.

Each raw bias is finite and satisfies -sigma_episode_start <= bias <= +sigma_episode_start.

On TD3-controlled decisions, the host executes Project[Actor(s) + raw_bias + original Gaussian noise].

Raw bias is added directly, without an extra sigma multiplication or annealing weight. It is fixed for the episode, while control eligibility and projection are evaluated at each decision.

The initial movement mask does not establish episode-long control eligibility.

[Routing output]

routing_prior has shape 16x17:
- Rows follow sender UAV IDs 0-15.
- Columns 0-15 are UAV actions.
- Column 16 is GS.
- Each sender's own column is WAIT.

Every value is finite and lies in [0,1]. Each row's sum differs from one by at most 10^-6.

This is an episode-fixed prior before legal masking. The epsilon-exploration branch uses 100% of the currently masked and renormalized prior. If legal mass is zero, the host falls back to legal-uniform exploration.

Greedy decisions and the original epsilon schedule remain unchanged.

[Conversion principles]

Follow the complete analysis's UAV IDs, directions, magnitudes, and probability-allocation rationale.

Convert a fraction of the bias bound into raw bias using the supplied current sigma_episode_start.

For unspecified entries, follow the analysis's choice of neutral guidance or reliable historical reuse:
- Neutral TD3 bias is zero.
- Neutral routing prior is uniform over 17 actions.

Unknown history means no reliable historical basis is available; new neutral guidance may be chosen.

Historical matrices are complete rounded reference values. Their rows may not sum exactly to one. When reusing historical probabilities, construct a valid new distribution satisfying the output requirements.

Reused historical bias must also satisfy the current bounds.

The input's three-decimal presentation rule does not restrict output precision. Use sufficient numerical precision to satisfy the bounds and row-sum tolerance.

[Response format]

Return exactly one complete JSON object containing only:
- td3_bias
- routing_prior

Include every matrix element as an evaluated finite JSON number.
