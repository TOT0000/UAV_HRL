Convert the first-stage analysis into numerical exploration guidance for TD3 and routing.

The system uses 16 UAVs to collect data and deliver it to GS. The objective is to maximize timely useful bits per joule of movement energy. Use the analysis, current state, numerical bounds, and previous-episode feedback to produce this episode's guidance.

[TD3 bias]

td3_bias must be a 16x3 matrix:
- Rows correspond to UAV IDs 0-15.
- Columns are speed, heading, and vertical.

Normalized actions are decoded as:
v_xy = 5 * (speed + 1) m/s.
theta = pi * heading rad.
v_x = v_xy * cos(theta), v_y = v_xy * sin(theta).
v_z = 2 * vertical m/s.

The domains of speed and vertical are [-1,1]. Heading is periodic in [-1,1). A speed value of 0 means a horizontal speed of 5 m/s.

Every bias must be finite and satisfy:
-sigma_episode_start <= bias <= sigma_episode_start.

On TD3-controlled decisions, the host executes:
Project[Actor(s) + td3_bias + original Gaussian noise].

The bias is added directly, without another sigma multiplication or an annealing weight. It remains fixed within the episode, while control eligibility and projection constraints are evaluated at each decision. The initial movement mask is not an episode-long eligibility constraint.

[Routing weights]

routing_weights must be a 16x17 matrix:
- Rows correspond to sender UAV IDs 0-15.
- Columns 0-15 correspond to UAVs 0-15, and column 16 corresponds to GS.
- A sender's own column represents WAIT. For example, column 3 is WAIT for UAV 3.

Weights must be finite and nonnegative. They do not need to sum to 1 and are not restricted to values at or below 1. They express relative preferences among one sender's actions. For example, [3,1,1] corresponds to probabilities [0.6,0.2,0.2]. Output the weights; the host computes the probabilities.

During epsilon exploration, the host removes currently illegal actions, normalizes the remaining weights, and samples from that distribution. If an entire row or its legal weights sum to zero, that UAV uses legal-uniform exploration while other UAVs retain their valid guidance.

When another legal action has positive weight, a zero-weight action cannot be selected. If WAIT is the only legal action with positive weight, exploration selects WAIT with probability 1.

Weights remain fixed within the episode. Greedy decisions and the epsilon schedule remain unchanged.

[Choosing numerical values]

Follow the analysis's UAV IDs, bias directions, magnitudes, and weight-allocation rationale. Convert TD3 magnitudes expressed as fractions of sigma into actual raw bias values.

For unspecified entries, follow the analysis's choice of neutral guidance or evidence-supported previous guidance:
- Neutral TD3 bias is zero.
- Neutral routing weights are 17 ones per row.

Reused TD3 bias must satisfy the current bounds.

Prefer integers or short decimals for weights. Use sufficient precision for TD3 bias to satisfy its bounds. Three-decimal input presentation does not restrict output precision.

[Output format]

Return only one complete JSON object containing td3_bias and routing_weights. Do not include Markdown code fences, comments, or explanatory text.

Every element must be a finite JSON number, not a string, expression, or ellipsis. Before responding, verify the matrix dimensions, TD3 bounds, and nonnegative weights. If validation feedback is provided, correct the identified errors and return both complete matrices.
